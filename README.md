# Éclat Café Showcase

Build a refined, responsive multi-page website for Éclat Café, Ascot Vale. The user has a real client lead: use ONLY authentic photos and brand assets sourced from their Instagram (https://www.instagram.com/eclat__cafe/?hl=en) or supplied business listing material. Do not generate, substitute, or use AI food photos. Use their Instagram logo/name styling where available. Design should feel elegant and adult: predominantly warm white and beige, understated dark text, no cartoonish styling, no oversized boxed cards, small-to-medium readable typography, and absolutely no overlapping text at any viewport. Include smooth tasteful animations and mobile-first polish. Pages: Home, Menu, Reviews, Contact, plus a clear top-left brand/logo symbol on every non-home page that returns to the homepage. Home should introduce the café, feature real Instagram food/interior images, location, service options, booking/order CTAs. Menu must include every menu item supplied by the user, grouped cleanly by category, with each item having its own real, separate photo ONLY if authentic matching imagery can be sourced from Instagram; do not invent or AI-generate. If a distinct authentic photo is unavailable, use an elegant non-image presentation instead rather than false imagery. Reviews page should use the supplied Google review quotes/rating (4.7 from 73 reviews) and selected customer feedback. Contact should include 234 Union Rd, Ascot Vale VIC 3032, Australia; +61 3 9578 0940; opening hours shown (Open, closes 3:30pm, verify/add appropriate presentation); map/directions, reservations/order links as available. Include all supplied menu text/prices accurately, including categories, dietary alternatives and add-ons. Make navigation clear and ensure the design is complete, high-quality, responsive, and ready to show a client.
